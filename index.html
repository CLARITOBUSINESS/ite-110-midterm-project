Project Overview



We live in the Philippines, where weather conditions can be tough to deal with.. especially for me, as I am sensitive to the heat. I wanted a quick way to check real-time weather details during heavy rain or extreme heat. Usually, when I search on Google, I have to scroll through a lot of unnecessary information before seeing the actual numbers like humidity and temperature. That’s why I chose to build this project. Since this is my first time building a web app, I thought it would be a great starting point, and I hope it turns out well.




Main Goal: To build a single-page web application that fetches real-time, location-based weather data and forecasts from a public API, allowing users to track live meteorological conditions smoothly and intuitively.
